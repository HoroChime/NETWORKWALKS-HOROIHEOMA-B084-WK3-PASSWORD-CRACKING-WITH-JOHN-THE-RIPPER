#  Password Cracking with John the Ripper (JTR)

##  Project Overview

This project is part of **Week 3 – Project Module 1** of my Cybersecurity & Ethical Hacking learning journey.

The objective was to recover the password of a password-protected PDF document using **John the Ripper (JTR)** and its graphical interface, **Johnny GUI**, on a Windows PC.

## 🛠️ Tools Used

- John the Ripper (JTR)
- Johnny GUI
- Windows PC
- Online PDF Hash Extractor

## ⚙️ Practical Tasks Performed

1. Downloaded and configured John the Ripper.
2. Installed and launched Johnny GUI.
3. Extracted the password hash from the protected PDF.
4. Saved the extracted hash in a text file (`hash1.txt`).
5. Imported the hash file into Johnny.
6. Initiated the password recovery process.
7. Successfully recovered the PDF password.

##  Key Learning Outcomes

- Understanding password hashing and PDF protection.
- Learning how password hash extraction works.
- Using John the Ripper for password recovery.
- Understanding the importance of password complexity.
- Recognizing the role of password auditing in cybersecurity.
